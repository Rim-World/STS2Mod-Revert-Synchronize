# 如果你喜欢本mod，也欢迎看看我的其它mod。或许对你有帮助。

## ① 效果

将游戏中的“同步”卡牌调整为 110 版本的效果：你每有一种不同的充能球，就在本回合获得 2 点集中（111版本为 1 点，107版本则带有消耗词条）。

升级后：每有一种不同的充能球，获得 3 点集中（107/111版本为 2 点）。

其余效果保持不变：1 费，技能牌，不消耗；卡面文本同步为 110 版本，卡图不变。

本 mod 直接在“同步”原卡牌上进行修改，并非生成新卡牌 + 禁用旧卡牌。

## ② 影响（基于本人游戏理解）

110 版本的同步显著强于其余所有版本，能够成为故障机器人职业的核心卡之一。

本 mod 影响存档：在 mod 开启时，历史记录中的“同步”卡牌按回调后的数值显示；关闭 mod 后会恢复原状。

## ③ 环境与版本

本 mod 不依赖任何基础 mod。

本 mod 支持 default 0.107.x 与 public beta 0.111.0 及以上版本；

在 v0.110.x 上自动停用：该版本的同步卡牌本就是目标效果，无须修改。

游戏启动时 Mod 检测游戏版本号和游戏包体是否存在同步卡牌，版本不支持或同步卡牌被移除、形状不符时，本mod会自动禁用；

理论上只要没有大的 api 更新或卡牌修改，本 mod 无须修改即可自动适配新版本。

## ④ 实现方式与兼容性

本 mod 采用最小依赖的方式写成，正常来说与大多数 mod 兼容，且不易随着版本变化而失效。

本 mod 采用外置补丁写死的方式，将同步卡牌的卡名、卡面文本、打出效果、关键词与升级效果固定为 110 版本的效果，但未写死卡面图片。

本 mod 在不同游戏版本的生效方式均相同。

但本 mod 不保证与盗版、修改版、移动版、老旧版本或者冷门 mod、次级 mod 的兼容性。
