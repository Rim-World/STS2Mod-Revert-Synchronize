# 调研笔记：Synchronize（同步）三版本差异与回退方案

日期：2026-08-16；只读取证，未触碰任何既有文件。

## 结论速览

- 「同步」= 塔2 故障机器人（Defect）技能牌 **Synchronize**（1 费 / Skill / Uncommon / Self，
  官方 zhs 译名「同步」，pck 本地化实证）。
- 机制：打出后获得 **SynchronizePower**（`TemporaryFocusPower`，本回合临时集中），
  层数 = `CalculationBase(0) + CalculationExtra × 不同充能球种类数`（按 Orb.Id 去重）。
- 三版本差异仅在数值/关键词（详见下），`OnPlay` 逻辑、`SynchronizePower`、费用/类型/稀有度/目标
  三版本完全一致；**卡图三版本同一张**（`images/packed/card_portraits/defect/synchronize.png` 系）。

## 三版本对照（反编译逐行 diff）

| 版本 | CalculationExtra | CanonicalKeywords | OnUpgrade | 实机效果 |
|---|---|---|---|---|
| v0.107 | 2 | [Exhaust] | RemoveKeyword(Exhaust) | 基础：2×种类 + 消耗；升级：2×种类 不消耗 |
| v0.110 | 2 | 空 | UpgradeValueBy(+1) | 基础：2×种类；升级：3×种类（无消耗） |
| v0.111 | 1 | 空 | UpgradeValueBy(+1) | 基础：1×种类；升级：2×种类（无消耗） |

官方补丁笔记（本机 v0.111.0 pck 内 `localization/eng/patch_notes/`，非第三方）：
- `2026_07_30.md`：*"Buffed Synchronize: Upgrade changed to increase temp focus from 2 -> 3. No longer Exhausts."* → 即 v0.110 定义。
- `2026_08_13.md`：*"Nerfed Synchronize: Focus decreased from 2(3) → 1(2)."* → 即 v0.111 现状。

## 补丁面取舍（对 107 的特别说明）

仅改 CanonicalVars 不足以在 107 得到 110 效果：
107 基础版带 Exhaust 关键词、升级只去消耗不加值。因此「彻底写死」方案必须同时覆盖
关键词与 OnUpgrade（+1），才能实现"无论哪个版本都统一为 110 效果"。

### ⚠️ 关键词补丁的虚分派陷阱（v1.1 教训）

107 的 `Synchronize` **override** 了 `CanonicalKeywords`（返回 `[Exhaust]`）；
把补丁打在基类 `CardModel.CanonicalKeywords` getter 上，虚方法分派会让实例调用直接走
override、不经过基类 getter → 补丁不触发（v1.0 在 107 上消耗问题即源于此）。
正确挂点：**`CardModel.Keywords` getter**（三版本均为非 virtual `GetKeywordsWithSources(All)`、
Synchronize 均不 override），Postfix 过滤 Exhaust 可兜住包括实例缓存（`_keywords`）、
107 override、战斗 hook 在内的一切来源。补丁基类 virtual 成员前必须确认目标类无 override。
