# 005 1.2.2（2026-11-13）

- 版本号：`1.2.2`
- 时间戳：2026-11-13（构建与部署）
- 开发人员反馈：0.107 用同步 + 历史课程时，自动打出的同步 dupe 会留在弃牌堆，等于本次战斗多一张同步。
- 实装更改概括：
  - `SynchronizeResultPilePatch.Postfix107` 只在原结果为 `PileType.Exhaust` 时改为 `PileType.Discard`。
  - 保留 dupe 的 `PileType.None`，让 0.107 原版结算走 `RemoveFromCombat`。
  - 版本 1.2.1 → 1.2.2。
- 简略技术细节：
  - 0.107 `GetResultPileTypeForCardPlay()` 先判断 `IsDupe || Type == Power` 返回 `None`；随后判断消耗。
  - 无条件改成 `Discard` 会覆盖 `None`；条件化后普通同步仍不消耗，dupe 正常移除。
  - 0.110 / 0.111 / 0.113 没有该方法，补丁不挂载。
- 失败经验或实验教训：
  - 改写 `__result` 的 Postfix 必须保留原方法所有分支语义；不能用「全部钉死」代替「只改需要改的分支」。
  - 临时复制体（dupe）的 `None` 不是「无结果」，而是「从战斗中移除」；覆盖它会制造额外卡牌。
- 提交编号：`6b68663`（功能提交；1.2.1 与 1.2.2 同批入库）。
