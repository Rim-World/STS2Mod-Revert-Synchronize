# 版本日志 001：v1.0

- 版本号：`1.0`
- 时间戳：2026-08-16
- 开发人员反馈：用户确认方案后开工；110 与 111 描述模板文字一致的推断经用户接受；v1.0 构建并安装到游戏后，用户报告 107 分支上「同步」打出后仍进入消耗区，问题转入 v1.1 修复。
- 实装更改概括：新增「回调同步」mod，把故障机器人技能牌「同步」整卡固定为 v0.110 定义——1 费、技能、目标自身、罕见、无消耗，基础每有一种不同充能球获得 2 点本回合集中，升级 3 点；v0.110.x 上自动停用；提供 16 语言卡名与描述。
- 简略技术细节：Harmony 外置补丁 12 个（`CanonicalVars`、`OnPlay`、`OnUpgrade`、关键词、悬停提示、费用两项、类型、目标、稀有度、卡名、描述），补丁体自包含且不读取原版实现；`SynchronizeShapeGuard` 做静态成员检查与 `ModelDb` 运行时检查；`ModConfig` 按 `ReleaseInfoManager.Instance.SemVer` 判断 `0.110.x` 并禁用补丁；本地化键使用 `RE_SYNCHRONIZE.title` 与 `RE_SYNCHRONIZE.description`，16 个语言文件由 `TOOLS/scripts/extract-synchronize-localization.py` 从官方 pck 提取后改写；pck 仅含图标与 16 个 `cards.json`；manifest 版本 `1.0`，`min_game_version` 为 `0.107.0`。
- 失败经验或实验教训：关键词补丁最初挂在基类 `CardModel.CanonicalKeywords` getter 上，107 的 `Synchronize` 对该属性有 override，虚分派绕过补丁，导致 v1.0 在 107 上打出仍消耗；补丁挂载前必须先确认目标类是否 override 了基类虚成员。另：计划与 ADR 记录了后续 v1.1、v1.2 的源码修订，但 manifest 版本未随之更新，仍为 `1.0`。
