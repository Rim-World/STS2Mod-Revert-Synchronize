# ADR-001：RevertSynchronize ——「同步」整卡回调至 v0.110

- 日期：2026-08-16
- 状态：已实施（v1.0 构建安装）→ v1.1 修复 107 虚分派问题 → **v1.2 关键词全路径下沉 + 打出钉死 + 诊断日志**，待实机复测
- 关联计划：`2.PLANS/001-G-同步卡回调施工计划.md`

## 背景

v0.111.0 将故障机器人卡牌「同步」（Synchronize）的临时集中从 2（升级 3）削弱为 1（升级 2）。
需求：整卡回调至 v0.110 效果（基础 2 / 升级 3、无消耗），所有卡牌形态统一；v0.110.x 上不生效。

## 决策

1. **彻底写死**（RevertBrightestFlame v1.1 同款）：12 个 Harmony 补丁 + 1 个守卫，
   补丁体全部自包含、不读取原版实现：
   CanonicalVars / OnPlay / OnUpgrade / CanonicalKeywords / ExtraHoverTips /
   CanonicalEnergyCost(+CardEnergyCost.Canonical 兜底) / Type / TargetType / Rarity /
   TitleLocString / Description。
2. **文本写死**：16 语言 `RE_SYNCHRONIZE.title/.description`，模板取自官方 pck 原文
   （SmartFormat 占位符 `{CalculationExtra:diff()}`/`{CalculatedFocus:diff()}` 由写死
   DynamicVars 渲染为基础 2 / 升级 3），`RE_` 前缀防键冲突。
3. **形状守卫**：静态成员存在性检查 + 运行时 `ModelDb.Card<Synchronize>()`；任一失败 → 整体禁用，不崩溃。
4. **版本门**：`ReleaseInfoManager.Instance.SemVer` 判 `0.110.x` → 补丁不生效（该版本已是目标效果，
   避免无谓干预）；懒求值 + 缓存，SemVer 未就绪时暂放行。
5. **版本门槛**：manifest `min_game_version=0.107.0`（加载器原生拒绝低版本）。
6. **素材**：不改卡图（三版本同一张）；pck 仅 16×cards.json + 空白占位 `mod_image.png`（420×420）。

## 备选方案与放弃原因

- 仅补 CanonicalVars 单点（ADR-002 之前的 BrightestFlame v1.0 风格）：107 上会得到
  「半回退」卡（基础仍有 Exhaust、升级不加值），与"所有版本统一为 110 效果"冲突，放弃。
- 版本门用加载器分支（PlatformBranch）：110 与 111 同属 beta 分支，无法区分，放弃。
- 运行时按版本条件编译/反射分派：107/110/111 相关 API 签名一致，无需分派，放弃。

## 影响

- 107/111/未来版本上，「同步」被固定为 110 定义（数值 2/3、无消耗、110 文案）。
- 110 上 mod 完全惰性（补丁不生效，卡牌保持原样）。
- 未来游戏改动 Synchronize 结构 → 守卫降级禁用补丁，需按 docs 维护清单回归。

## 修订记录

### v1.1（2026-08-16）：107 虚分派问题

- 107 实测基础版仍消耗：根因 = 关键词补丁打在基类 `CanonicalKeywords` getter，
  而 107 的 Synchronize override 了该属性（虚分派绕过基类补丁），Exhaust 进入实例缓存。
- 修复：关键词补丁改挂 `CardModel.Keywords` getter，Postfix 过滤全部来源的 Exhaust。
  版本 1.0 → 1.1。

### v1.2（2026-08-16）：关键词全路径下沉 + 打出钉死 + 诊断日志

- 107 实测 v1.1 后打出仍消耗（图鉴文本带消耗、对局文本无消耗、日志确认补丁已应用）。
- 结论：107 上存在绕过 `Keywords` getter 的关键词读取路径（canonical 缓存、GetKeywordsWithSources
  直接调用、第三方 mod hook），v1.1 过滤点不足。
- 修复：① 过滤下沉到 `CardModel.GetKeywordsWithSources`（三版同名、一切读取必经点）；
  ② 条件补丁 `Synchronize.CanonicalKeywords`（107 特有 override）清源头；
  ③ 条件补丁 107 `GetResultPileTypeForCardPlay` 钉死 `PileType.Discard`；
  ④ 诊断日志（过滤首触发 + 条件挂载状态）。版本 1.1 → 1.2（manifest 于 2026-11-01 同步改为 1.2）。
